# Relational Operators

This topic covers the use of relational operators in Python to compare
numbers, characters, strings, and other values.

## Topics Covered

- Greater than 70
- Greatest among two numbers
- Greater than or Equal to
- Equal to
- Compare First & Last Letters
- Compare Sum of the Digits
- Validate Password
- Compare First Three Characters
- Check Last Part of a String

## Operators Practiced

- `>` Greater than
- `>=` Greater than or equal to
- `==` Equal to

## Learning Goal

The goal of this topic is to understand how relational operators can be
used to compare values and make simple decisions in Python.
