# Python String Methods

## 📌 Description
This topic covers commonly used Python string methods to perform different operations on strings, such as changing case, searching, replacing, and checking characters.

## 📚 Methods Covered
- `upper()` – Converts a string to uppercase.
- `lower()` – Converts a string to lowercase.
- `capitalize()` – Capitalizes the first character.
- `title()` – Capitalizes the first letter of each word.
- `swapcase()` – Changes uppercase to lowercase and vice versa.
- `strip()` – Removes spaces from both ends.
- `lstrip()` – Removes spaces from the left side.
- `rstrip()` – Removes spaces from the right side.
- `replace()` – Replaces a substring with another substring.
- `find()` – Returns the index of the first occurrence.
- `count()` – Counts occurrences of a substring.
- `startswith()` – Checks whether a string starts with a given value.
- `endswith()` – Checks whether a string ends with a given value.
- `split()` – Splits a string into a list.
- `join()` – Joins elements using a separator.
- `isalpha()` – Checks whether all characters are alphabets.
- `isdigit()` – Checks whether all characters are digits.
- `isalnum()` – Checks whether all characters are letters or digits.
- `isspace()` – Checks whether all characters are whitespace.

## 💻 Example
```python
text = "hello world"

print(text.upper())
print(text.capitalize())
print(text.title())
print(text.replace("world", "Python"))
print(text.find("world"))
```

## 🖥️ Output
```text
HELLO WORLD
Hello world
Hello World
hello Python
6
```
