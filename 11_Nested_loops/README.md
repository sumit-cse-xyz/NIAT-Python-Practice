# Python Nested Loops

## 📌 Description
A nested loop is a loop inside another loop. It is used to execute a set of statements repeatedly within another loop.

## 📚 Concepts Covered
- Nested `for` loops
- Outer loop and inner loop
- Using nested loops to print patterns
- Understanding loop execution

## 💻 Example
```python
for i in range(1, 4):
    for j in range(1, 4):
        print(j, end=" ")
    print()
```

## 🖥️ Output
```text
1 2 3
1 2 3
1 2 3
```

## 🎯 Learning Outcome
Learned how nested loops work and how to use them to print patterns and repeat operations.

## 🛠️ Technology Used
